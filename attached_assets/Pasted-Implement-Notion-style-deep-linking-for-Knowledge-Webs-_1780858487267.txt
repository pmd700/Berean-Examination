Implement Notion-style deep linking for Knowledge Webs and Standalone Mind Notes using Neon/Postgres database IDs.



Goal:

When I open a Knowledge Web or Standalone Mind Note, the browser URL should point to that exact item. Refreshing the page, opening the URL in a new tab, or copying/sharing the URL should reopen the same item. I should be able to bookmark an exact note on my browser and come back to it now that we have deep links.



Use stable Neon/Postgres database IDs as the source of truth.



Routes:



- /knowledge-webs/:webId

- /notes/:noteId



Optional prettier routes if easy:



- /knowledge-webs/:slug-:webId

- /notes/:slug-:noteId



Important:

The slug/title is cosmetic only. The database ID is the real source of truth because titles can change or duplicate.



Required behavior:



- Clicking a Knowledge Web updates the URL to that web’s route.

- Clicking a Standalone Mind Note updates the URL to that note’s route.

- On browser refresh, read the route param and fetch the matching record from Neon by ID.

- Opening the URL in a new tab should load the same web or note.

- Do not keep selectedWeb/selectedNote only in temporary React state.

- Route params should restore the selected item after reload.



Neon/database instructions:



- Do not manually require any Neon dashboard changes unless the current schema lacks stable primary keys.

- First inspect the existing Neon/Postgres schema.

- If Knowledge Webs and Standalone Mind Notes already have stable id primary keys, use those.

- Only add a migration if absolutely necessary.

- Do not use note titles as IDs.

- Do not use temporary client-generated UI state as IDs.



Replit/server instructions:



- Make sure direct refreshes on nested routes work.

- If using React Router with browser history, configure the Replit/Express/Vite server fallback so routes like /notes/:noteId and /knowledge-webs/:webId return index.html instead of 404.

- Prefer clean URLs.

- If clean refresh-safe routes are not possible on Replit, use hash routes as a fallback:

    - /#/notes/:noteId

    - /#/knowledge-webs/:webId

Do not change the editor.

Do not change saving, deleting, linking, sidebar layout, note layout, or markdown behavior.

Only implement URL-persisted navigation/deep linking backed by Neon database IDs.
