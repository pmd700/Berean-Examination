2. Add API route:

GET /api/brain/search

Query params:
- q required
- scope optional: all, sources, cards, connections
- web_id optional
- source_type optional
- processing_status optional
- card_type optional
- status optional
- created_by optional
- limit optional

Return a combined result list shaped like:

{
  "results": [
    {
      "result_type": "source" | "card" | "connection",
      "id": 123,
      "web_id": 456,
      "title": "Result title",
      "snippet": "Short relevant preview only",
      "match_reason": "Matched source summary / card title / connection evidence",
      "score": 1,
      "metadata": {}
    }
  ]
}

Rules:
- Require authentication.
- Only return current user’s data.
- Do not return full raw_text in search results.
- For brain_sources, include processing_status.
- For cards/connections, default to status = confirmed unless status is explicitly provided.
- Allow include_suggested=true if easy, but default should not mix suggested AI drafts into normal confirmed search.

4. Add API route:

GET /api/brain/sources/:id/context

Purpose:
Return one source plus its processed AI analysis and any linked cards.

Return:
- source metadata
- raw_text only if query param include_raw=true
- metadata_json.ai_processing_v1

Rules:
- Require authentication.
- User can only access their own source.
- Default should not return full raw_text unless include_raw=true.

5. Add API route:

POST /api/brain/context-pack

Purpose:
Build a compact context pack for future chatbot use.

Body:
- query optional
- web_id optional
- source_ids optional
- card_ids optional
- include_neighbors optional default true
- limit optional

Return:

{
  "query": "...",
  "sources": [],
  "cards": [],
  "connections": [],
  "notes": []
}

Rules:
- This route does not call AI.
- This route does not answer the user.
- This route only gathers relevant context.
- Keep the response compact enough to later pass into an AI prompt.
- Include IDs and titles so future AI answers can cite exact cards/sources.
