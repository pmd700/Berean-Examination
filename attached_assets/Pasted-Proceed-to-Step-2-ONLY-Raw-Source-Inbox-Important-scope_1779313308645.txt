2. Add API routes for brain_sources only.

Create routes like:

POST /api/brain/sources
Purpose:
Create a raw source.

Body:
- web_id optional
- title required
- source_type required
- source_url optional
- raw_text required
- metadata_json optional

GET /api/brain/sources
Purpose:
List current user's raw sources.

Optional filters:
- web_id
- source_type
- processing_status

GET /api/brain/sources/:id
Purpose:
Read one source owned by the current user.

PATCH /api/brain/sources/:id
Purpose:
Update metadata only.

Allowed PATCH fields:
- title
- source_type
- source_url
- web_id
- metadata_json

Disallowed PATCH fields:
- user_id
- raw_text
- processing_status
- processed_at
- created_at
