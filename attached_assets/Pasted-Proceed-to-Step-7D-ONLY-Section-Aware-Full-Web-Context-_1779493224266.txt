2. Add section retrieval helpers.

Likely location:
server/brainRetrieval.ts

Add read-only helpers such as:

Section match rules:
- exact title match should be strongest
- normalized title match should work: “Monday” == “monday”
- query containing section title should match: “Daily Schedule Monday” should match section “Monday”
- section matching should consider web name too when available
- if multiple sections match, rank by title match, web relevance, and query coverage

Card-in-section rule:
A card is inside a section if the card center point is within the section rectangle.

Use:
cardCenterX = card.x + card.width / 2
cardCenterY = card.y + card.height / 2

Then:
section.x <= cardCenterX <= section.x + section.width
section.y <= cardCenterY <= section.y + section.height

If width/height is missing, use x/y with a safe fallback.

3. Add retrieval mode to get_brain_context_pack.

Add optional parameter:

retrieval_mode: "auto" | "search" | "section" | "web"

Default:
retrieval_mode = "auto"

Behavior:
- auto:
  - if query matches a section, use section-aware retrieval
  - otherwise use existing semantic retrieval
- section:
  - force section-aware retrieval
  - if no section is found, return a clear markdown note and optionally fallback to search
- search:
  - existing 7B/7C semantic behavior
- web:
  - return full web context when web_id is provided or web name is strongly matched
  - use cautiously with limits so it does not explode token usage

Do not break existing callers that do not pass retrieval_mode.
