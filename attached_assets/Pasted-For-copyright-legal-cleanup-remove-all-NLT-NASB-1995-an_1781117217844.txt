## Hard rules

1. **Do not modify ESV, LSV, BSB, or KJV.**
2. Keep the existing ESV API integration unchanged.
3. Do not delete or weaken any NLT/NASB parser, renderer, schema, UI architecture, or reintegration pathway.

## Remove the copyrighted text/data

Remove all NLT, NASB 1995, and NASB 2020 textual content from every location where it exists, including:

* Neon/Postgres rows and tables containing those translation texts
* seed data and import outputs
* JSON, EPUB, RTF, TXT, SQL, generated files, and attached assets
* static/public assets
* caches and generated bundles containing embedded text
* test fixtures containing real translation text
* hardcoded verses or footnotes
* server endpoints that return stored text
* fallback text and offline caches
* project exports or data dumps located inside Replit

Delete bible **translation content**, not reusable code or schemas.

When deleting database data, report only:

* table name
* translation identifier
* number of rows deleted

Never output the verse text.

Preserve all code and concepts supporting:

* ordered rich-text segments

* verse numbers
* superscript note markers
* footnote markers

* clickable popup data

* translation notes
* rich chapter rendering
* annotation anchoring
