The Goal: We need to implement a "Hybrid Markdown Export." The application currently stores its state (nodes, edges, coordinates) in JSON. We want users to be able to export their board to a .md file that serves two distinct purposes:

LLM-Readable Context: The top of the Markdown file must contain beautifully formatted, human/LLM-readable text of the debate arguments.

App State Restoration: The bottom of the Markdown file must contain the exact, raw JSON state of the application hidden within an HTML comment (``).

When a user uploads this .md file back into the application, the app must parse the hidden JSON and perfectly restore the board (nodes, edges, coordinates).

Feature 1: The Export Function (exportBoardToMarkdown)
Write a JavaScript function that takes the current boardState object.

Step 1: Iterate through boardState.nodes. Format each node into a Markdown string using the format: ### [Author] (Node ID: [ID])\n[Text]\n\n---\n\n.

Step 2: Stringify the entire boardState object.

Step 3: Append the stringified JSON to the bottom of the Markdown string wrapped exactly like this: \n.

Step 4: Create a Blob with the type text/markdown.

Step 5: Create a temporary object URL, generate an invisible <a> tag, set the download name to board_export.md, trigger the click to download, and clean up the DOM and URL object.

Feature 2: The Import Function (importBoardFromMarkdown)
Write an asynchronous JavaScript function that takes a File object (from an <input type="file" />).

Step 1: Read the file content as text using await file.text().

Step 2: Use a Regular Expression to extract the JSON string hidden inside the HTML comment block. The regex should account for newlines and grab everything between ``.

Step 3: Parse the extracted string back into a JSON object.

Step 4: Include try/catch blocks for JSON parsing errors and alert the user if no valid board data is found in the Markdown file.

Step 5: Return the parsed state object so the application can update its internal state (nodes and edges).

Implementation Details:
Please provide the vanilla JavaScript implementations for both functions. Assume boardState looks roughly like this:

JSON
{
  "nodes": [{ "id": "1", "author": "David", "text": "Argument text", "x": 100, "y": 200 }],
  "edges": [{ "id": "e1", "source": "1", "target": "2" }]
}
After providing the core functions, please provide a brief example of how to wire these functions up to standard HTML buttons (<button id="export"> and <input type="file" id="import">).
