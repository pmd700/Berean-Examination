3. Authentication for Step 6A

Because this is a sensitive personal second brain, do NOT expose unauthenticated access to private brain data.

Implement one of these safe options:

Preferred simple option for Step 6A:
- Require a server-side MCP bearer token secret.
- Use env var: MCP_BRAIN_TOKEN.
- Incoming MCP requests must include:
  Authorization: Bearer <token>
- If missing or wrong, return 401.

Important:
- Do not hardcode the token.
- Do not expose the token to frontend code.
- If MCP_BRAIN_TOKEN is missing, the MCP endpoint should be disabled or return a clear 503 configuration error.

User scoping:
Because MCP_BRAIN_TOKEN is a server-level bridge token, Step 6A can initially support only the authenticated owner/admin user if the current app has an owner identity env var available.

Use this order:
1. If OWNER_AUTH0_USER_ID exists, use that as the MCP user_id.
2. Else if OWNER_EMAIL exists and can be resolved safely to a user, use that user.
3. Else return a clear 503 saying MCP owner user is not configured.

Do not allow arbitrary user_id from the MCP client.
Do not accept user_id from tool arguments.
Do not let ChatGPT choose which user to query.

4. Read-only MCP tools to expose

Expose these tools only:

Tool 1: search_second_brain

Input:
- query required string
- scope optional: all, sources, cards, connections
- web_id optional
- limit optional

Behavior:
- Reuse /api/brain/search logic or shared helper.
- Return compact results only.
- Do not return full raw_text.

Tool 2: get_brain_context_pack

Input:
- query optional
- web_id optional
- source_ids optional array
- card_ids optional array
- include_neighbors optional boolean default true
- limit optional

Behavior:
- Reuse existing context-pack helper.
- Return sources/cards/connections/notes.
- Compact output only.
- Include IDs and titles for citation.

Tool 3: get_card_context

Input:
- card_id required number

Behavior:
- Reuse existing card context logic.
- Return card, direct neighbors, touching connections, linked sources.
- Do not modify anything.

Tool 4: get_source_context

Input:
- source_id required number
- include_raw optional boolean default false

Behavior:
- Reuse existing source context logic.
- Default include_raw=false.
- If include_raw=true, allow only if the implementation already confirms ownership through the fixed MCP owner user.
- Prefer returning processed AI analysis and snippets.
