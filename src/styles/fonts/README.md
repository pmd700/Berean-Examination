# Emoji fallback

Unmodified Noto Color Emoji COLRv1 font, downloaded October 17, 2026 from
https://github.com/googlefonts/noto-emoji/blob/main/2D/fonts/Noto-COLRv1.ttf.
Distributed under SIL OFL 1.1; see OFL.txt for the complete license.

Placed after the existing named text fonts. macOS prefers Apple Color Emoji;
Windows/Linux prefer this bundled fallback. Unicode text, editing, copying and
exports are unchanged.
